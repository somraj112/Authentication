# **authentication-01**
test
A simple **basic authentication API**.
Built for beginners to understand the foundations of user authentication.

### **Uses**

* Learn how user signup & login works
* Understand password hashing (using bcrypt)
* Learn how to structure a basic authentication API
* Perfect starting point before moving to sessions and JWT

---

# **authentication-02**

A **session-based authentication system** where the server stores the login session and the browser stores a session ID.

### **Uses**

* Learn how cookies + sessions work together
* Understand how traditional websites (like older PHP/Express apps) handle auth
* Learn session storage, session management, and logout mechanisms
* Useful for apps where server-side control of sessions is required

---

# **authentication-03**

A **stateless JWT authentication system**.
No server-side session storage — authentication is handled entirely using cryptographically signed tokens.

### **Uses**

* Learn how JSON Web Tokens work
* Build stateless, scalable authentication for APIs
* Perfect for SPAs, mobile apps, microservices
* Understand token signing, verification, expiration, refresh tokens
* Learn modern industry-standard authentication flow
